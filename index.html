About

Built where systems stay up.

Operations first. Automation second.
Both in the same head.

I came up monitoring live network and M-Pesa infrastructure across Safaricom’s SOCs — IP, Transmission, RAN, Digital Services, Core — watching business processes run and break in real time. That floor taught me the job an NSOC actually does: notice the degradation before the customer does, classify it honestly, escalate it to the right team with the right context, and keep the clock inside the SLA. ITIL gave me the vocabulary; CCNA and JNCIA gave me the layer-3 reasoning underneath it.

The other half of my work is removing the toil: automations and RAG systems that own the repetitive flows — routing, notifying, reporting, answering from real documents — so the people on shift spend their attention on the incidents that need a human. I build iteratively, design for failure modes before happy paths, and I’m finishing AWS AI Practitioner on the way to AI/ML agent engineering.

FEATURED

RAG Chatbot

A retrieval-augmented chatbot that answers from your documents — chunk, embed into ChromaDB, retrieve top-k context, then generate a grounded reply instead of free-wheeling from the model alone.

Why this way

Pure LLM chat invents details when it doesn’t know. RAG forces every answer through ChromaDB-retrieved chunks first — the hard part was balancing chunk size against recall so answers stayed specific without missing the right passage.

# RAG retrieve → generate (ChromaDB) — representative excerpt
import chromadb
from chromadb.utils import embedding_functions

client = chromadb.PersistentClient(path="./chroma_db")
embed_fn = embedding_functions.DefaultEmbeddingFunction()
collection = client.get_or_create_collection(
    name="docs",
    embedding_function=embed_fn,
)

def answer(query: str, k: int = 4) -> str:
    hits = collection.query(query_texts=[query], n_results=k)
    chunks = hits["documents"][0]
    context = "\n\n".join(chunks)

    prompt = (
        "Answer using ONLY the context below. "
        "If the context is insufficient, say you don't know.\n\n"
        f"Context:\n{context}\n\nQuestion: {query}"
    )
    return llm.generate(prompt)  # grounded reply, not free-form guesswork
